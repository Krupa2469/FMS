# FMS Web v1.3.0 — Data Import Utility

- Added Data Import card in Utilities.
- Added generic Data Import Utility at pages/admin/data-import.html.
- Supports upload/paste for PDF, image, CSV, Excel, JSON and text documents.
- Extracts required fields for CPGRAMS/grievance types, LAQ, LCQ, RTI and DISHA.
- Provides preview, database verification, import/update, duplicate matching and JSON download.
- Preserves existing Firestore fields using merge updates.
- Existing All Grievances prepared import utility is retained.
