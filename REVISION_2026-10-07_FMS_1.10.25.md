# FMS Version 1.10.25 — 07-Oct-2026

## Report label cleanup

- Removed the visible `GRIEVANCES —` prefix from section column headings in Reports and Export Preview.
- Removed the visible `GRIEVANCES —` prefix from GRIEVANCES summary/dashboard card labels in Reports and Export Preview.
- Internal module-qualified field references remain unchanged, so mixed-module section mapping and filtering continue to work.
- RTI and DISHA prefixes are retained when they are needed to distinguish fields/cards from other modules in a mixed-module report.
- Export formats inherit the cleaned labels because they use the same report section/summary definitions.
- Version updated to 1.10.25.
