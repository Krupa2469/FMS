# FMS Version 1.10.4 — 02-Oct-2026

## RTI Dashboard Simplification

- RTI dashboard now shows only five current-financial-year summary cards:
  - RTI Applications
  - Within Due Date
  - Due Today
  - Overdue
  - Disposed / Closed
- Removed dashboard cards for section/reply workflow and first/second appeal metrics from the RTI home screen.
- Applied elegant light pastel card backgrounds with dark readable text and subtle borders/shadows.
- Five RTI cards fit evenly across a wide desktop screen and remain responsive on smaller screens.
- Existing RTI data entry, appeal fields, registers and reports remain available; only the dashboard card display was simplified.
- Application version updated to 1.10.4.
