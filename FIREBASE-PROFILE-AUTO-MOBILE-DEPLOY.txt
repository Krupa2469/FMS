Rose Gardens - Auto Mobile Mapping + Resident Profile Backend (v1.2.236)

To enable automatic registered-mobile mapping and Resident Profile functions, deploy:

  firebase deploy --only functions:residentLoginDirectory,functions:activateResidentSession,functions:getResidentProfile,functions:updateResidentProfile

residentLoginDirectory supplies the mapped phone to the login code without displaying it on the page.
If an older directory function is still deployed and does not supply the phone, v1.2.236 automatically shows a Registered Mobile Number fallback field so residents are not locked out.

activateResidentSession remains authoritative: after Firebase OTP verification it checks the verified number against the selected resident record in Firestore.
