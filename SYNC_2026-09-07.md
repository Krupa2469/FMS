# CRD-TG-FMS Web / Android Sync — 7 September 2026

This revision establishes the feature-rich web source in this package as the common application baseline for both platforms.

- Web runtime files are synchronized across the Web and Android packages.
- Android launches the same synchronized web runtime from packaged app assets, keeping dashboards, CPGRAMS, RTI, DISHA, reports, utilities, document parsing, office processing and shared Firebase behavior aligned with Web.
- Android retains the native Kotlin source as a fallback/reference, but `MainActivity` is the synchronized WebView shell.
- Missing Admin Master/Grid CSS and the legacy CPGRAMS Search controller/reference paths were repaired.
- JavaScript syntax and local HTML asset references were validated before packaging.

Firebase project configuration is intentionally retained unchanged.
