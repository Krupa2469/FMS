# FMS Version 1.10.2 — 02-Oct-2026

## UI Redesign Update

This release refreshes the application interface across Home, CPGRAMS, RTI, DISHA, Utilities, Master Tables and Reports pages.

### Main changes
- Redesigned **sidebar** with a dark operational-desk style, bold menu items and improved hover state.
- Redesigned **dashboard cards** with colorful rectangular cards inspired by the CPGRAMS operational desk layout.
- Redesigned **registers** with cleaner white surfaces, dark table headers, improved row spacing and better hover readability.
- Redesigned **data entry forms** with modern rounded inputs, stronger labels, improved focus state and cleaner card sections.
- Refreshed **toolbars, buttons, page headers and footer** for a more production-ready consistent visual style.
- Applied the refreshed UI styling through the application by enhancing the common stylesheet used by module pages.
- Version updated from **1.10.1** to **1.10.2**.

### Notes
- This update is primarily a **visual redesign** and does not change business logic.
- Existing functionality, links, registers and pending workflows remain intact.
