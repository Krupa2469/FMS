# FMS Version 1.10.9 — 02-Oct-2026

## Navigation and module-screen corrections
- Corrected module screens so the common Government/FMS header appears only once.
- Removed legacy duplicate headers such as the old RTI Register and DISHA module headers.
- Added a clear module-name strip immediately below the common header. It displays the current context such as CPGRAMS, Prajavani, Public Grievances, RTI, DISHA, etc.
- Expanded the common navigation row to include all Home sidebar functions: Home, CPGRAMS, Grievances, Appeals, Prajavani, Public Grievances, Direct Complaints, LAQ, LCQ, Court Cases, VIP References, CMO References, PMO References, Audit Paras, Vigilance Cases, RTI, DISHA, Utilities, Master Tables and Reports.
- Navigation remains a single horizontal row with horizontal scrolling on smaller screens.
- Moved the main Save / Update / Delete buttons from the top toolbar to below the data-entry area for CPGRAMS/Grievances, RTI and DISHA.
- Removed the old DISHA fixed toolbar/header spacing that was covering portions of the new common header.
- Updated application/cache-busting version references to 1.10.9.
