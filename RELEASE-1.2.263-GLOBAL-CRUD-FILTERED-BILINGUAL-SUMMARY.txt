Rose Gardens RGMS 1.2.263 - Global CRUD, Filtered Register, Resident Directory and Bilingual Fund Summary

1. Global CRUD consistency
- Static audit covers 107 Save/Update/Delete/Clear/Refresh/Upload/Publish/Assign-style action buttons; each has a JavaScript or inline handler reference.
- Store success operations emit a friendly success notification.
- Final Firebase CRUD errors emit a friendly error notification even if the module catches the Promise.
- Runtime and unhandled Promise errors are surfaced to the user.

2. Filtered registers / dashboard drill-down
- Dashboard drill-down records display full-screen over the dashboard instead of underneath the cards.
- Complaint, Visitor, Document, Meeting and General Information filtered registers hide their summary cards and data-entry form while the filter is active.
- Report drill-down registers are full-screen with Close control.

3. Resident dropdown consistency
- All resident pickers use the normalized Residents Master as the authoritative source.
- Distinct Firestore resident documents are preserved even if a legacy Resident ID is duplicated.
- Names are whitespace-normalized and sorted alphabetically; H.No. is a secondary tie-breaker.
- Selection identity prefers the Firestore document id so no resident is lost due to duplicate legacy IDs.
- Ganesh, Colony Fund, Complaints, Visitors and Role Master resident pickers refresh after Residents Master CRUD.

4. Bilingual combined Fund Summary report
- New Reports option: Colony + Ganesh Fund Summary (Telugu / English).
- Telugu is shown on top and English below.
- Colony Fund Summary shows Current FY and Current Month values for:
  Total Houses (Occupied/Vacant), Total Expected Fund, Collected Fund, Pending Fund, Expenditure and Balance.
- Ganesh Festival Fund Summary retains its existing fields/calculations.
- Section headers: Colony Fund Summary and Ganesh Festival Fund Summary, with Telugu above English.
- Same bilingual content is used for report display and PDF/Excel/JPEG export paths.
