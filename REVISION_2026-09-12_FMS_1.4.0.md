# FMS Web v1.4.0 — Form Fields Master Population Fix

- Form Fields Master now auto-populates with the current CPGRAMS, other grievances, LAQ/LCQ, RTI and DISHA data-entry field definitions.
- Form Name, Section Name, Field Type and Source Master are now dropdowns.
- Form Name and Section Name dropdowns include existing Form Fields Master data plus built-in FMS form definitions.
- Duplicate checking for Form Fields Master now uses Module + Grievance Type + Form Name + Section Name + Field Key instead of Name.
- Form Fields Master register sorting now follows Module, Grievance Type, Form Name, Section and Display Order.
- Built-in master values are seeded automatically on opening Master Tables.
