Rose Gardens RGMS v1.2.241 - Fix 24
Association + Colony Dashboard authoritative initialization and calculations

Fixed:
1. Removed duplicate global Colony Fund constants/functions between Association Dashboard and Colony Fund Dashboard. These globals could collide when both modules were visited in one login session, causing a module script to fail or calculations to change depending on navigation order.
2. Dashboard module navigation now waits for a fresh Firebase snapshot before running Association/Colony dashboard initializers.
3. Forced refresh now truly waits for any older in-flight Firebase read and then performs a fresh read, preventing an empty auth-restoration snapshot from being reused until browser refresh.
4. Association occupancy now derives one classification per H.No.:
   - Total Houses = unique H.No.
   - Occupied = Owner-occupied + Tenant-occupied
   - Owners / Tenants = house classifications
   - Vacant = unique vacant houses
5. Restored a clickable Vacant card to the Association Dashboard.
6. Colony Fund rules are centralized and shared by both dashboards:
   - Monthly amount = Rs.500
   - Eligibility = Resident Type Owner and occupied by Owner (Vacant/Tenant occupation excluded)
   - Expected FY = eligible owner houses x Rs.500 x months accrued in selected FY
   - Expected Month = eligible owner houses x Rs.500
   - Collected = unique paid owner-month obligations x Rs.500
   - Pending = Expected - Collected
   - Tenant payments are not credited to the Owner just because the same H.No. is shared.
   - Expenditure uses Colony/Development/Maintenance fund expenditure only.
   - Balance = Collected - Colony Fund Expenditure.
7. Current FY/month labels are generated dynamically rather than remaining hard-coded.
8. Colony Total Houses now shows all unique houses; Expected/Collected/Pending use eligible occupied Owners only.
9. Colony dashboard drill-down respects FY vs current-month clicks and uses the same owner eligibility rules.

No Firebase Functions changes are required for this dashboard fix.
Deploy hosting only after replacing the project files:
  firebase deploy --only hosting
