# FMS Web v1.4.5 — CPGRAMS Default and Document Auto-Fill

- Grievances module now opens CPGRAMS by default when opened from Home.
- CPGRAMS dashboard, register and data-entry form are visible without manually selecting Grievance Type.
- Upload Grievance Document now parses the document and populates matching CPGRAMS data-entry fields.
- Parser normalises OCR/PDF text, extracts registration number, dates, complainant details, address/location, subject and grievance description, and calculates the 21-day due date.
- Existing user selection for Prajavani, Public Grievances, LAQ, LCQ and other types is retained after the user changes the dropdown.
- App version updated to 1.4.5.
