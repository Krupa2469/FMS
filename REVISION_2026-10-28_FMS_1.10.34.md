# FMS Version 1.10.34 — 28-Oct-2026

## Changes
- Updated the common FMS header address from **#6-3-6-605** to **#6-3-605**, retaining the full address: `#6-3-605, Anand Nagar Colony, Khairatabad, Hyderabad-500 004`.
- Removed the visible **RTI Application Number** field from the RTI Data Entry form.
- RTI Application Number is retained only as a hidden internal/legacy value so existing records and numbers extracted from uploaded RTI documents remain compatible.
- RTI Application Number is no longer mandatory for Save/Update.
- Application Date and Due Date now use the full available row width after removing the visible number field.
- Updated application/cache version references to **1.10.34**.
