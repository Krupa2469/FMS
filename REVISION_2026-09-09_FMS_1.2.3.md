# FMS Web v1.2.3 — Home, Grievances and Navigation Enhancement

- Home now has dedicated **Master Tables** and **Central Reports** cards.
- Home no longer shows a redundant FMS Home button.
- User-facing CPGRAMS module navigation is renamed **GRIEVANCES** while the existing Firestore collection remains unchanged for compatibility.
- Every module screen has common navigation: **Home | GRIEVANCES | RTI | DISHA**.
- Grievance module order remains **Dashboard Cards -> Grievance Data Entry**.
- Added required **Grievance Type** dropdown with the Home grievance-card types and a matching Grievance Types master register.
- Export/Print buttons were removed from module screens, registers, daily status, Master Tables and Reports Master. Export buttons remain only in **Central Reports**.
- Report titles now use **“as on DD/MM/YYYY”** (without the word “Date”).
- Central report module label changed from CPGRAMS to **GRIEVANCES**.
- Existing data and collection names are preserved for backward compatibility.
