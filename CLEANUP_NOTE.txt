PARSING ENHANCEMENT - 2026-08-10
---------------------------------
Added a central document parsing architecture across the active FMS data-entry modules.

1. js/services/fms-parser-service.js - common parse/fill/notification service.
2. js/services/fms-parser-ui.js - common Parse & Fill UI for CPGRAMS, RTI and DISHA.
3. js/services/parser/module-parsers.js - shared RTI, DISHA, CPGRAMS and generic field parsers.
4. js/document/document-engine.js - extended to OCR image files and route module parsers centrally.
5. pages/document-parser.html - standalone Central Document Parser Center.

Supported document inputs: PDF, TXT, PNG and JPG/JPEG. Scanned PDFs/images use Tesseract OCR when loaded.
Existing module-specific parsing and upload code has been retained for backward compatibility.
Parsed values are used to populate only empty fields; existing manual values are not overwritten.
All JavaScript files passed Node syntax validation after the enhancement.
