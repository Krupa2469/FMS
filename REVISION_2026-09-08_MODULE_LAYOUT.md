# FMS Module Layout Revision — 2026-09-08

- Active modules are CPGRAMS, RTI and DISHA only.
- Every active module opens in this order: **Dashboard Cards → Data Entry Form**.
- Every dashboard number is clickable and opens the corresponding filtered register.
- Filtered register mode hides dashboard/search/summary/export cards and expands the filtered data to full available width.
- The filter and Financial Year remain in the URL while filtered data is displayed.
- Module A was removed completely from pages, scripts, reports and navigation.
- Main/home navigation opens the combined module page directly.
- Separate legacy module-dashboard page/controller removed; each module now has a single combined landing page.
