# FMS Version 1.10.26 — 07-Oct-2026

## Report layout refinement

- Report section tables now auto-size columns proportionally to the actual heading/content instead of visually spreading columns evenly.
- S.No./Sl.No. columns remain compact; date/status/name/text columns receive appropriate relative widths.
- Long values wrap inside their own cells without disturbing adjacent columns.
- The same auto-fit logic is applied to Reports screen, Export Preview, Print, PDF, JPEG and improved Excel column widths.
- Replaced dark report section/table styling with a light elegant theme:
  - pastel summary cards
  - light-blue Summary and section headings
  - light table headers with dark text
  - subtle borders and alternate-row shading
- All existing report definitions, section-wise filters, summary cards, sorting, exports and sharing remain unchanged.
