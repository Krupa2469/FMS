# FMS Version 1.10.12 — 05-Oct-2026

## Register and report column alignment correction

- Corrected register table auto-fit behavior across CPGRAMS, Prajavani, Public Grievances, Direct Complaints, LAQ, LCQ, RTI, DISHA, Reports and master/register grids.
- Column headings are no longer broken in the middle of words (for example `District`, `Communication`, `Received`, `Document`, `Action`).
- Full column names are preserved; wide registers can scroll horizontally instead of compressing headings into unreadable fragments.
- Serial-number columns remain compact.
- Action columns remain compact and keep action buttons together.
- Long data values can wrap without disturbing header alignment.
- Report preview / print export tables now use automatic column layout and preserve complete headings.
- Version updated to **1.10.12** with updated cache-busting references.
