# FMS 1.9.2 - Report Layout Consistency

## Reports / Export Layout
- Standardized the report content width so the Government header, report title/meta, Summary section, and detailed data table align to the same report width.
- Summary now uses the same full report width as the detailed table in JPEG, PDF, Print, and on-screen Export Preview.
- PDF Summary and data tables now use identical left/right margins and table width.
- JPEG export uses one calculated report width for the header, Summary, and data table.
- Print layout uses one full-width report shell for all report sections.
- Existing report fields, DISHA six-column status report, report filters, and export/share functionality are retained.
