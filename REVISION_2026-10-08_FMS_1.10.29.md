# FMS Version 1.10.29 — 08-Oct-2026

## Report table fit and no-wrap identifiers
- Grievance No., Appeal No., Application No. and similar identifier columns no longer wrap.
- Report section tables now fill the same content width as the Summary area and section heading.
- Column proportions are calculated from headings and actual content, then normalized to the available report width.
- Compact S.No., date and status columns are retained; names and descriptive fields receive proportionate remaining width.
- Applied to Reports page, Export Preview, Print, JPEG and PDF.
- PDF tables now expand/shrink to the report content width while protecting identifier columns with larger natural widths.
- Existing report sections, section-wise filters, summary cards, exports and sharing remain unchanged.
