# FMS Version 1.10.27 — 07-Oct-2026

## Report compact auto-fit column widths

- Reduced report table column widths so columns no longer stretch across the full report width unnecessarily.
- Report columns now use compact content-aware widths rather than percentage widths.
- S.No. remains narrow.
- Date columns remain compact.
- Status/type columns use compact widths.
- Name and number fields receive only the space needed for readable content.
- Long text fields such as Subject, Description, Information, Question, Answer and Remarks retain additional width and wrap when needed.
- Applied to the Reports page, Export Preview, Print, JPEG, PDF and Excel exports.
- PDF tables now use their natural compact width when possible instead of automatically occupying the full landscape page.
- Existing light/elegant report colours and all report configuration features remain unchanged.
