Rose Gardens Web v1.2.237 - Resident Login and Resident UI Fix

1. Resident Login
   - Removed Registered Mobile Number entry field completely.
   - Resident selects Name only.
   - OTP is sent to the mobile number mapped to that resident in Firestore.

2. Resident Home

   - Mobile grid uses responsive columns instead of forcing label overflow.

3. Colony Payments
   - Removed blue card/background treatment.
   - Paid, Due and Ganesh Chanda use light neutral/pastel cards with dark text.

4. Bill Payments
   - Replaced dark/blue cards with light pastel cards and dark readable labels.
