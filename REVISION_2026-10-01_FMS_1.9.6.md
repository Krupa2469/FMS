# FMS 1.9.6 — Home Sidebar and Current-FY Dashboards

- Removed the Financial Year selector from the FMS Home page. Home always uses the current financial year.
- Added a Home-only sidebar with CPGRAMS, Prajavani, Public Grievances, Direct Complaints, LAQ, LCQ, Court Cases, VIP References, CMO References, PMO References, Audit Paras, Vigilance Cases, RTI and DISHA.
- Removed the visible Financial Year and Grievance Type dropdowns from the Grievances home screen. The grievance type is selected from the Home sidebar and the module always uses the current financial year.
- Home dashboard cards now show one current-financial-year value only; the Total and FY sub-labels were removed.
- RTI, Grievances and DISHA workflow dashboards use the current financial year only.
- DISHA dashboard cards no longer mix all-years totals with current-FY values.
- Removed workflow-dashboard status/title lines such as “Financial Year … / All years …” from all three modules.
- DISHA home register continues to use the current financial year and is sorted by meeting date with the latest date first.
- Application version updated to 1.9.6 with cache-busting references.
