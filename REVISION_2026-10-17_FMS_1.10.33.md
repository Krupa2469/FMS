# FMS Version 1.10.33 — 17-Oct-2026

## Consolidated Status Report

Added a ready-to-use **Status Report — Consolidated** in Reports.

### Report heading
- Main heading: **Status Report**

### GRIEVANCES
- Shows only records that are currently pending/open.
- Pending records are separated by grievance/reference type: CPGRAMS, Prajavani, Public Grievances, Direct Complaints, LAQ, LCQ, Court Cases, VIP References, CMO References, PMO References, Audit Paras and Vigilance Cases.
- CPGRAMS pending appeals are shown in a separate section.
- Pending grievance/RTI sections are current-status sections and are not restricted only to the current FY, so older still-pending cases remain visible.

### RTI
- Shows only RTI applications that are still pending/open.

### DISHA
- Shows meetings held in the **current Financial Year** only.
- Meetings are divided into Financial Year quarters: Q1 (Apr–Jun), Q2 (Jul–Sep), Q3 (Oct–Dec), Q4 (Jan–Mar).
- Only quarters up to the current quarter are considered.
- Future meeting dates are excluded from Meetings Held.

### Empty sections
- Any section with no matching data is omitted completely.
- No empty table, zero-column section or “No records found” block is shown for that section.

### Status summary
The report includes compact summary cards for:
- Pending Grievances
- Pending CPGRAMS Appeals
- Pending RTI Applications
- DISHA Meetings Held in the current FY through the current quarter

### Existing features retained
- Mobile responsive report layout
- Print / PDF / JPEG / Excel / Share
- Auto-fit columns and no-wrap identifiers
- Existing custom Reports Master definitions and reports
