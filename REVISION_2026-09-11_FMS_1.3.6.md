# FMS Web v1.3.6 — Sticky Actions, Full-Screen Registers/Form and Home Totals

- Action button rows are sticky/frozen on all screens.
- Register table headers are sticky while scrolling.
- Dashboard filtered registers and full registers open in full-screen mode hiding other screen elements.
- Register View/Edit opens the data-entry form in full-screen mode with the selected record populated.
- Added Utilities -> Mark Grievances Disposed one-time utility to update existing active grievance records to Disposed.
- Home dashboard cards show both total records and current FY records, with both numbers clickable.
- Prepared All Grievances import defaults as Disposed for future re-imports.
