# FMS 1.8.0 - DISHA district dashboard scope correction

- Removed the PoM Pending dashboard card.
- Districts with no meetings: Total uses all active DISHA meeting records; selected FY uses only the displayed financial year.
- Districts conducted meetings: Total uses all active DISHA meeting records; selected FY uses only the displayed financial year.
- Dashboard numeric links now pass an explicit all-years or FY scope to the register.
- Retained PoM Not Uploaded, Meetings Held, dynamic Sl.No., FY filtering and register sorting.
