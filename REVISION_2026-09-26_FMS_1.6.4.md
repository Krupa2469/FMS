# FMS v1.6.4 — Grievance Register Return Navigation & Dashboard Legibility

- Full-screen grievance Data Entry **Back to Register** now preserves the active `grievanceType` and financial year when returning to the shared grievance register.
- The behavior applies to Prajavani and every grievance type using the shared CPGRAMS/grievance form and register.
- Dashboard card values use a smaller responsive font for improved legibility, including combined Total / FY figures.
- No grievance field, register-column, OCR/parser, attachment, or calculation changes are included in this revision.
