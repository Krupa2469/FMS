# FMS Version 1.10.8 — 02-Oct-2026

## Common header applied throughout FMS

A single standard Telangana FMS header is now used on every HTML screen/page in the application.

### Header format
- **GOVERNMENT OF TELANGANA** — 22 pt, Bold
- **OFFICE OF THE COMMISSIONER, RURAL DEVELOPMENT** — 20 pt, Bold
- **#6-3-6-605, Anand Nagar Colony, Khairatabad, Hyderabad-500 004** — 12 pt
- **FILE MANAGEMENT SYSTEM** — 18 pt, Bold

### Coverage
The common header is applied to Home, CPGRAMS/Grievances, RTI, DISHA, registers, daily status pages, Utilities, Reports, Dashboard, Master Tables, Reports Master, Registers Master, data import/admin utility pages and the 404 page.

### Other details
- Retained the Telangana emblem on the left side of the common header.
- Header background remains Telangana/FMS blue.
- Previous page-specific header blocks are suppressed so only the new standard header is displayed.
- Application version and cache references updated to **1.10.8**.
