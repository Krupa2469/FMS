RGMS 1.2.245 - Fix 26

1. Ganesh Contribution report reconciliation
- Current-FY report includes a contribution when either its stored FY matches the selected FY OR its actual date falls in the FY range.
- This handles historical Firestore rows with stale FY/date metadata and keeps the report count aligned with the Ganesh Festival Fund register.

2. Laddu Auction dashboard amount
- Normalizes legacy Firestore Laddu rows whose amount was stored in amountPaid/paidAmount/amount instead of auctionAmount.
- Existing positive-amount Laddu rows created before Payment Status was introduced are treated as legacy Paid rows unless an explicit status says otherwise.
- Ganesh Festival dashboard, Association dashboard, and clickable Laddu drill-down now use the same normalized paid auction records from the Firestore-backed Ganesh collections.
