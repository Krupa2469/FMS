Rose Gardens v1.2.282
Date: 2026-09-12

Reports
- Replaced the visible report Period label with As on Today and the current date.
- Report Range remains available only as the filter selector so Current FY, Calendar Year and Custom Range filtering continue to work.
- HTML/PDF/Excel/JPEG report headings use As on Today consistently.

Expenditure Details
- Standard columns: S.No., Description, Amount, Advance, Balance to be paid, Remarks.
- Expenditure Register and exports use the same labels.
- Expenditure summary cards use Amount, Advance and Balance to be paid.
- Ganesh dashboard expenditure-specific cards now use Amount, Advance and Balance to be paid while the Ganesh Festival fund-summary metrics remain available separately.

Data Entry Fields Master
- Added Admin > Data Entry Fields master for centralized field maintenance across modules.
- Supports Module, Section/Form, Existing Control ID, Field Key, Field Label, Field Type, Options, Required, Visible, Display Order, Status and Remarks.
- Built-in field labels/visibility/required/type/select options can be modified centrally.
- New custom fields can be added and are stored in each record under customFields.
- Baseline definitions are seeded for core resident, collection, festival, complaint, meeting, document, notice, information, communications, reports/expenditure and admin/master screens.
