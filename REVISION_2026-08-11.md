## Important deployment note

The static Firebase Hosting application cannot itself wake up at 11:00 AM and send WhatsApp messages. The scheduled Cloud Function must be deployed. Firebase scheduled functions use Cloud Scheduler and are billed; Firebase documentation states that Cloud Functions deployment requires the Blaze plan.
