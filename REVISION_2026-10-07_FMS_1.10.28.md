# FMS Version 1.10.28 — 07-Oct-2026

## Compact report width consistency
- Reduced Report Summary/dashboard card area width.
- Summary area and report body now use the same compact width derived from the widest report section/table.
- Export Preview paper width is automatically sized from the report content instead of using a wide fixed canvas.
- JPEG export canvas is reduced to the report content width.
- Print layout uses the same compact report width.
- PDF summary and section blocks use a centered compact content width.
- Existing light elegant colours, report sections, section-wise filters, summary selections and exports remain unchanged.
