# CRD-TG-FMS Revision — 13 August 2026

Changes in this package:
1. FMS Module Dashboard now has only one FMS Home button (right side); the duplicate left button was removed.
2. FMS Home Dashboard now includes the CPGRAMS category selector with CPGRAMS as the default: Prajavani, Public Grievances, Direct Complaints, Assembly Questions, Court Cases, VIP References, CMO References, PMO References, Audit Paras and Vigilance Cases.
3. FMS Home cards no longer show “current-FY record(s)” or Open buttons.
4. Financial Year selectors are populated from records and also retain the current and previous four FYs for reliable selection.
5. CPGRAMS dashboard category matching tolerates singular/plural wording differences.
6. CPGRAMS central document parser was fixed by loading the FMS Central Document Engine before the parser service.
7. CPGRAMS Grievance Number duplicate validation is now case/space insensitive, applies to both Save and Update, and excludes the current record during editing.
8. CPGRAMS register displays fallback values for legacy Grievance ID/Number field names.
9. Existing project files and current functionality are retained.
