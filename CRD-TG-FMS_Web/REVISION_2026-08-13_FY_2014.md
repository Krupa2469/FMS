# CRD-TG-FMS — FY Selector Revision

- Financial Year selectors now always contain FY 2014-15 through the current financial year.
- The current FY is selected by default.
- Any FY found in existing records is retained as well.
- Applied to FMS Home Dashboard and module dashboard, and automatically to CPGRAMS, RTI and DISHA register selectors because they use the shared FMSFY utility.
- No Firebase initialization or Git configuration changes were made.

## CPGRAMS Category Dashboard Navigation Fix
- CPGRAMS dashboard category dropdown is now functional.
- Selecting Prajavani, Public Grievances, Direct Complaints, Assembly Questions, Court Cases, VIP References, CMO References, PMO References, Audit Paras, or Vigilance Cases updates the dashboard immediately.
- The selected category is preserved in the URL so the respective dashboard view can be refreshed/shared and browser Back/Forward works.
- CPGRAMS remains the default category.
