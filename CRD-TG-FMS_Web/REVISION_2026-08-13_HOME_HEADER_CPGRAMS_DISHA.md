# FMS Revision — 13 August 2026

## Implemented
- Standard Telangana Government header updated to:
  - GOVERNMENT OF TELANGANA,
  - OFFICE OF THE COMMISSIONER, PANCHAYAT RAJ & RURAL DEVELOPMENT,
  - #6-3-607, Anand Nagar Colony, Khairatabad,
  - Hyderabad - 500004
- FMS Home: removed FMS Home button and Financial Year selector.
- FMS Home: displays current FY pending data only.
- FMS Home card order: CPGRAMS, Prajavani, RTI, DISHA, followed by remaining CPGRAMS categories.
- CPGRAMS register: removed visible/system-generated Grievance ID from the data-entry form and register grid.
- CPGRAMS register columns reordered to Sl.No., Grievance No., Grievance Subject, Complainant Name, District, Received Date, Due Date, Concerned Officer, Current Status, Remarks, Action.
- CPGRAMS Excel/PDF/JPEG exports use the same ten data columns (Action excluded) and include the standard header.
- Central FMS Reports now support JPEG export and standard header in Excel/PDF/JPEG.
- Daily-status Excel service now includes the standard header on exported sheets.
- Masters: Home/Back buttons added; master Code is read-only and auto-generated by master type; changing master type refreshes the existing grid data.
- External Portal Integration: Telangana eOffice replaced by DISHA Portal Integration at https://erp.disha.gov.in/.
- DISHA Meeting Details: Choose Meeting Document field added; selecting a document automatically parses and populates DISHA fields. Separate central parser UI removed from the DISHA page.
