Rose Gardens v1.2.266 — Admin Role Access Runtime Scope Fix

Root cause confirmed from browser console:
- admin.js bindRoleAccessRuntimeEvents() referenced saveAccessForm, deleteAccessForm,
  clearAccessForm and populateAccessForm from a different lexical scope.
- This threw "ReferenceError: saveAccessForm is not defined", aborted the Admin
  module, and could affect navigation even while another module such as Reports
  was visible.

Fixes:
1. Added an explicit RGMSAdminRoleAccessRuntime bridge owned by the consolidated
   Admin-master scope.
2. initializeAdmin now binds Role Access events through that bridge.
3. initializeAdmin renders the Role Access register through
   RGMSAdminMasterRegisters instead of referencing an IIFE-local function.
4. Event binding is idempotent to avoid duplicate Save/Delete/Clear handlers.
5. Cache-busting/version references advanced to 1.2.266.

No data model, fund-calculation, bilingual-report, or CRUD business rules were
changed in this hotfix.
