# FMS Version 1.10.17 — 07-Oct-2026

## Corrections

1. **DISHA sidebar pending count**
   - DISHA sidebar count now represents **current financial year PoMs pending** only.
   - It no longer shows all DISHA records / all-years file counts.
   - Clicking DISHA from the sidebar opens the current-FY `pom-pending` register.

2. **Pending Alerts popup**
   - The **Pending Alerts** heading and close button remain fixed.
   - Only the alert list below the heading scrolls.
   - Existing complainant/appellant-wise pending-day alerts remain unchanged.

3. **Date Received duplicate field**
   - Removed the duplicate DD/MM/YYYY date field created from the hidden native date picker.
   - CPGRAMS and all grievance types now show a single Date Received field with one calendar button.
   - The hidden native picker is explicitly excluded from the common date-display formatter.

## Version
Application/cache version updated to **1.10.17**.
