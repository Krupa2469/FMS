ROSE GARDENS - RESIDENT LOGIN MAPPED OTP FIX (v1.2.237)

Resident Login now works exactly as follows:
- Resident selects only his/her Name.
- No phone-number field is shown.
- The app resolves the mobile number mapped to that resident in Firestore.
- OTP is sent to that mapped number through Firebase Phone Authentication.
- After OTP verification, activateResidentSession again checks the verified phone against the selected resident record.

IMPORTANT - DEPLOY THE UPDATED FUNCTIONS
From the firebase-functions folder/project, deploy:

  firebase login
  firebase use rose-gardens-cheeryal
  firebase deploy --only functions:residentLoginDirectory,functions:residentLoginPhone,functions:activateResidentSession

Then deploy Firebase Hosting and refresh the site.

The new residentLoginPhone callable is required when the resident directory itself does not return phone numbers.
The phone number is never shown as an editable field on the Resident Login screen.
