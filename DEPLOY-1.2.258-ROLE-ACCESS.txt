Rose Gardens 1.2.258 deployment

IMPORTANT: The officer Role Access Save fix requires BOTH the updated app files and updated Firestore Security Rules.

1. Deploy/copy the Web files as usual, then deploy Hosting.
2. Deploy the included firestore.rules from the Firebase project root.

Recommended commands in your Firebase project folder:

firebase deploy --only firestore:rules
firebase deploy --only hosting

If your Web folder does not contain firebase.json, use the Android source folder supplied with this release to deploy the rules:

firebase deploy --only firestore:rules --project rose-gardens-cheeryal

Then refresh the browser, log in with the office-bearer account, open Role Access Master and Save/Update.
